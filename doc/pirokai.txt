*pirokai.txt*  Monokai Pirokai colorschemes for Neovim

Monokai Pirokai provides two dark colorschemes. Neovim 0.10+ is required.

Use one of these commands in your config or at the command line: >
    colorscheme pirokai-arctic
    colorscheme pirokai-sunset
<
No setup call is required.

The colorschemes set terminal colors and include Neovim, Tree-sitter, LSP,
diagnostic, and optional plugin highlights. See the README for the supported
plugins and installation examples.

For lualine, use `pirokai-arctic` or `pirokai-sunset` as the theme.
Palette tables are available at `require("pirokai").palettes`.
